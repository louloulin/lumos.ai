```rust

    .build()?;
```

### 3. 完整的错误处理体系

提供企业级错误处理模式：

```rust
// 分层错误处理
match agent.chat(message).await {
    Ok(response) => handle_success(response),
    Err(LumosaiError::APIError(msg)) => handle_api_error(msg),
    Err(LumosaiError::NetworkError(err)) => handle_network_error(err),
    Err(err) => handle_unknown_error(err),
}
```
