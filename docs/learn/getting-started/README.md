## 📦 前置要求

### 系统要求
- **操作系统**: Linux, macOS, 或 Windows
- **Rust版本**: 1.70 或更高版本
- **内存**: 至少 4GB RAM (推荐 8GB+)
- **网络**: 需要访问AI模型API（如OpenAI）

### 开发工具（推荐）
- **IDE**: VS Code + rust-analyzer
- **终端**: 任意现代终端
- **Git**: 版本控制（用于克隆示例）

### AI模型API
- **OpenAI API Key** (推荐用于快速开始)
- 或其他支持的模型API
